# 七大宗罪 · 制作说明

50 秒 / 1920×1080 / 30fps。全部由代码渲染（MotionHarness），没有用任何素材贴图。

## 一句话结构

**开场（复用七大奇迹）→ 七宗罪标题卡 → 六个罪（每罪 8 拍）→ 傲慢长铺垫 → drop 上傲慢现身 → 欲望收尾**

## 音乐

- 曲目：`霓虹兔 - Chaikovsky.mp3`
- 实测 **132 BPM**（梳状滤波 131.8，次选 66.0 是半速），drop 精确在 **91.640s**
- 视频长 50s，drop 必须落在傲慢出场：`offset = 91.640 - 41.818 = 49.822`
- 一拍 0.454545s，一小节 1.818s。**所有切点都在鼓点网格上**

## 音效（83 条，全部代码合成）

`build_audio.py` 直接 import `timeline.js` 的锚点，所以画面和声音不可能对不上。

自制音效（`.tmp/gen_sfx.py`）：
- `chime` / `chime_hi` — 结构出现的清脆音（6 个非谐分音 + 瞬态咔哒）
- `hit` / `hit_soft` — 重音（下滑正弦 + 噪声爆 + 中频敲击）
- `point` / `point_hi` — 光点点亮（短促音 + 咔哒）
- `boom` — drop 低频轰（30→120Hz 下滑 + 长尾）
- `tick_soft` — 独白行出现

**光点音效**：开场 7 个光点各一个 `point`；每罪的 12 只羽毛眼各一个 `point_hi`
（时间 = 第二拍 + 0.02 + i×0.062，和 `drawSin` 里的 `haloProgress` 完全一致）。

**音乐闪避**：重音前 0.16s 开始压，压 5dB（不是 6dB 以上，压太狠音乐变形），
重音后 0.42s 恢复。这样重音有"让位"的感觉，但音乐不会跳。

## 踩过的坑

1. **`glowText` 用堆叠偏移会糊字**。一开始叠 8 方向 × 4 层，大字直接变成一团白块。
   正解：先画一层 `ctx.filter = blur()` 的模糊副本，再把实心字盖上去。
   验证方法：读帧算字形内部亮度均匀性，`period 2/4 spread` 应 < 1。
2. **`drawBackground` 里 `globalAlpha` 泄漏**。尘埃循环设了 alpha 没恢复，
   后面所有文字都被压到 26%。凡是循环里改 `globalAlpha` 必须 `save/restore`。
3. **闪白太亮太长会把整屏冲灰**。0.62 强度 + 140ms 让 20.0s 那帧整屏均值 173，
   左区 100% 像素 > 140，文字全看不见。降到 0.20 强度 + 45ms 才像闪白。
4. **罪名的 0.2s 退场淡出会留黑帧**。改成 0.13s。
5. **`mh preview --times` 要 JSON 数组**：`--times '[1.5,4.5]'`。
6. **不要用正则从 JS 里抠数值**。`export const BEAT = 60 / BPM` 会被抠成 `60`。
   改成写一个 `dump_anchors.mjs` 用 node 真正 import 模块再输出 JSON。
7. **mh runtime cache 会卡死**（`Runtime cache is invalid ... Operation timed out`）。
   删 `~/AppData/Local/mh/cache-v2/runtime/<hash>` 和同名 `.lock` 再重试。
8. **第二拍不能只换文字**。第一版第二拍只是文字变了，音效 x0.55（因为音乐在那个
   位置最响，短音效被淹没）。修法：a) 重音层加长尾 `boom`，b) 闪避提前 0.16s，
   c) 大字带横向滑入 + 下落，让"切"看得见。修后 x1.12~1.36。

## 数值验证（别信肉眼，也别信视觉模型）

`verify_sync.py` 抽 PCM 和低分辨率帧，检查：
- 每个锚点前后 100ms 的 RMS 比值（1.0 = 没变化）
- 帧间差找切点位置
- 亮度找闪白帧

实测结果：
```
sin1..sin6 第二拍   x1.12 ~ 1.36
DROP 41.818        x2.69   ← 全片最大跳变
视频切点            5.43/9.07/12.70/16.33/19.97/21.80/25.43/41.80/44.53
闪白最亮帧          41.83s (lum 210.6)  ← 正好在 drop
```

## 改版 2（按老大反馈）

### 反馈与处理
| 反馈 | 怎么改的 | 数值验证 |
|---|---|---|
| 音效小、音乐大 | 音乐整体 -8.5dB（原 -4），闪避 7dB（原 5）；重音全部降 2~3dB | 各段 RMS 下降，音效占比上升 |
| 傲慢出场音效必须最大 | boom/hit 提到 0dB 并叠 sub，drop 前 0.1s 加深闪避 | **41.80s 是全片最响的 200ms 窗口**（RMS 0.192，第二名 0.155）；跳变 x4.26 |
| 人物同质化 | ① 每罪加**内部纹路**（色欲竖光条、暴食同心环、贪婪横币条、懒惰睡眠带、愤怒裂痕、嫉妒鳞片、傲慢放射光）② 每罪加**胸口徽章**（心/碗/币堆/钟/星爆/大眼/王冠） | 胸章区亮像素：贪婪 90%、色欲 39%、暴食 12.7%；人物区结构差异 6.4~15.3 |
| 二次卡点要睁眼 | `drawEye` 支持 `eyeOpen`，用 `easeOutBack` 弹开（有回弹），虹膜+瞳孔+高光逐层显现 | 眼睛区亮像素 9.82% → 16.42% → 17.05% |
| 人物占比太小 | headR 0.178→0.185，加**身体轮廓**（肩+胸，画到画面外），肩宽放宽到 ±2.2/2.3 | 宽 45.5%、高 97%（对标 47%/87%） |
| 傲慢轮廓别一下出来 | `haloDraw` 让光环像笔一样画出来（带笔尖光点），`bodyProgress` 让身体从领口长出，`detailAlpha` 让纹路最后浮现 | 人物像素 23752→30603→43528→57452→77163（六行独白逐步推进） |

### 新参数
- 人物：`headR = H * 0.185`，`fx = W * 0.700`，`fy = H * 0.330`
- 身体坐标：`BODY_LEFT/BODY_RIGHT`，从领口 (y≈1.76) 画到 y=3.7（画面外）
- 音乐增益 `MUSIC_GAIN_DB = -8.5`，闪避深度 7dB，归一化到 -0.6 dBFS
