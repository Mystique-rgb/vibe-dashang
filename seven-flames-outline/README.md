# 斗破苍穹 · 七大异火 · 勾勒重击版

VIBE 知识大赏短片。横版 1920×1080，30 fps，1,505 帧，50.167 秒。章节按异火榜从低到高倒数。

原曲《霓虹兔 - Chaikovsky》按 100/99 倍速映射到 0.450 秒拍格，原曲 91.640 秒对齐成片 41.400 秒。前六章从可移动的笔尖开始勾勒，随后轮廓内逐步填色，名称在第二次重击落下。右侧的陨落心炎为火蟒，三千焱炎火为带龙角、鳞眼与龙须的盘龙，虚无吞炎为黑紫鬼脸。压轴四张大字卡在 43.200、44.567、45.900、47.267 秒入画。

开场扫描音和标题钟击来自《七大发明-物件音效版》的开场混音，新增击点叠在原有层上。各章二次重击保留同源钟声，其他段落用低音体、清脆攻击、贴合火焰细节的拟音和压轴字卡音。字幕以两条为上限，完整资料保留在《完整文案》。

## 编辑与导出

用 MotionHarness 打开此目录即可预览、修改与重导。`src/timeline.js` 管理上屏文字、章节和卡点，`src/scene.js` 管理版式及转场，`src/outlined.js` 绘制七种异火，`src/flame-ring.js` 绘制火环，`src/cover.js` 是竖版封面场景。`assets/mix.wav` 是可直接渲染的成品音轨，`assets/sync.json` 记录对齐和混音测量结果。完整简介及出处见《完整文案》。

```sh
mh open . --browser
mh render 七大异火.mp4 --json '{"fps":30,"quality":"high"}'
```

需要重新混音时，用 Python、NumPy、SciPy 和 FFmpeg 运行 `python mix.py "原曲文件路径"`，会重新生成 `assets/mix.wav` 和 `assets/sync.json`。

## 音频

`assets/mix.wav`（或 `mix-captions.wav`）是构建产物，不进仓库。
clone 后先跑目录里的构建脚本（`mix.py` / `scripts/prepare.py` / `scripts/audio-mix.py`）生成，
否则 `mh preview` 会报 `Could not resolve ... wav`。
