标题、章节和收尾用低亮度 42 齿旋转齿轮与局部扫光。七簇异火分别使用熔岩爆裂、水涡、心火脉冲、冰晶、锁链、妖火气流与吸入音，与名牌的干净钟击分层。封面规格为 1080×1440，画面采用压轴的黑焰和紫色齿轮。

## 编辑与导出

用 MotionHarness 打开此目录即可预览、修改与重导。`src/timeline.js` 管理上屏文字、章节和卡点，`src/scene.js` 管理版式及转场，`src/flames.js` 绘制七种异火，`src/cover.js` 是竖版封面场景。`assets/mix.wav` 是可直接渲染的成品音轨，`assets/sync.json` 记录对齐和混音测量结果。完整简介及出处见《完整文案》。

```sh
mh open . --browser
mh render 七大异火.mp4 --json '{"fps":30,"quality":"high"}'
```

需要重新混音时，用 Python、NumPy、SciPy 和 FFmpeg 运行 `python mix.py "原曲文件路径"`，会重新生成 `assets/mix.wav` 和 `assets/sync.json`。
