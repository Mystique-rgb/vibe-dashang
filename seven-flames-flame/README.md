# 斗破苍穹 · 七大异火 · 火焰环版

VIBE 知识大赏短片。横版 1920×1080，30 fps，1,505 帧，50.167 秒。章节按异火榜从低到高倒数。

原曲《霓虹兔 - Chaikovsky》按 100/99 倍速映射到模板 0.450 秒的拍格，原曲 91.640 秒对齐成片 41.400 秒。前六章每章 3.6 秒，先让异火生长，1.8 秒后名称与火焰同时落拍。七个名牌之后第 8、10 帧分别出现说明，各配一声 1,480 Hz / 1,960 Hz 短计时音。压轴的虚无吞炎首次完整出现后再进入分条介绍。

开场沿用《七大发明-物件音效版》的六次扫描、1.800 秒钟击落标题和后续三次脉冲。`assets/intro-original.wav` 是对应工程的原始开场混音，原样保留到 5.320 秒，随后用 80 ms 接入异火混音。后半片的铭牌钟声复用同源 `bell-tone.wav`。

标题、章节、压轴和收尾使用有火舌和飞散火星的火焰环。普通章节沿原画已有的火丝、花瓣和轮廓逐段勾勒，约 1.46 秒显出完整主体，火环同时向两侧合拢。陨落心炎和三千焱炎火恢复原造型。冲刺阶段右侧连续显示。虚无吞炎在 41.400 秒重拍点火，从 42.400 秒起在画面四处分拍落下带倾角的关键词。说明仍在铭牌后的第 8、10 帧出现，末行在第 13 帧扫入并配轻提示。普通章节的火焰和火环在第二次卡点前压暗，随铭牌抬亮。对齐参考片的主字高度和右侧图形范围，五字异火名只在横向收宽。四组压轴关键词的下坠时长为 3 帧，破空声在下坠时进入，重击紧贴落地帧。

## 编辑与导出

用 MotionHarness 打开此目录即可预览、修改与重导。`src/timeline.js` 管理上屏文字、章节和卡点，`src/scene.js` 管理版式及转场，`src/flames.js` 绘制七种异火，`src/stroke-reveal.js` 沿原画笔路径控制线条显现，`src/flame-ring.js` 绘制火环，`src/cover.js` 是竖版封面场景。`assets/mix.wav` 是可直接渲染的成品音轨，`assets/sync.json` 记录对齐和混音测量结果。完整简介及出处见《完整文案》。

```sh
mh open . --browser
mh render 七大异火.mp4 --json '{"fps":30,"quality":"high"}'
```

需要重新混音时，用 Python、NumPy、SciPy 和 FFmpeg 运行 `python mix.py "原曲文件路径"`，会重新生成 `assets/mix.wav` 和 `assets/sync.json`。
