# 斗破苍穹 · 七大异火（初版）

50.167 秒 / 1920×1080 / 30fps / 1505 帧。章节按异火榜从低到高倒数。

**这是初版**，后续演进成 `seven-flames-flame`（火焰环版）和 `seven-flames-outline`（线稿勾勒版），
最后定型为仓库里的 `seven-flames`。三版共用同一份时间轴和文案。

## 目录

```
src/           场景代码
assets/        sync.json（画面锚点与音乐时间对齐表）
mix.py         从源素材重跑混音 → assets/mix.wav（不进库）
完整文案.md     全片逐镜文案
```
