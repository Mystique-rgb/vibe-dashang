# 假如你是牛顿

MotionHarness Standard 工程。1920×1080，30 fps，共 3616 帧。剧情与台词字卡以《分镜脚本.md》为准，音乐从原曲第一帧顺放，33 场、87 镜。

## 时间轴

| 位置 | 动作 |
| --- | --- |
| 0:00.10 / 0:00.43 / 0:00.87 | 铜坠边缘、绷绳和下落跟原曲开头动作 |
| 0:02.60 | 第一记重拍从井沿切向下落 |
| 0:54.25 左右 | 果实落地先声入镜 |
| 1:37.43 | 近景留住未闭合的轨迹和低音留白 |
| 1:38.33 | 轨道揭晓。30 fps 第 2950 帧首次出现完整轨道 |
| 2:00.53 | 尾版与配乐收束 |

## 工程内容

- `mh.json` 声明画幅、时长和两条独立音轨。`music.mp3` 为原曲，`foley.wav` 为无对白拟音。
- `src/storyboard.js` 记录各镜头的帧入口和正文字幕。`src/captions.js` 控制第二句字卡、注释、片名和尾版的出字点。
- `src/act-one.js`、`src/act-two.js` 和 `src/act-three.js` 分别绘制来路、发现和轨道高潮。`src/atmosphere.js` 管理色调、空气光、局部高光与少量重拍亮起。

在工程目录运行 `mh open --browser` 即可进入 Studio。可用 `mh preview --time 98.333 --output .tmp/轨道.png` 查看回鼓帧，也可用 `mh render 假如你是牛顿.mp4` 导出。
