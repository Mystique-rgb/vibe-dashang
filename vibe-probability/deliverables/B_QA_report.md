## 一、本版核心变更

用户要求两件事：

1. **把所有音效都去掉，只保证标记的位置有音效**
2. **音效要多样化，模仿或复用对标视频的音效**

### 1.1 音效从 145 个事件砍到 36 个

| | 改前 | 改后 |
|---|---|---|
| 事件数 | 145 | **36** |
| 有声时间占比 | ~28% | **9.0%** |
| 有声段数 | 贯穿全片 | **17 段**（对应 19 个标记，3 组同刻合并） |
| 其余时间 | 有转场音、打字音、滚动音 | **完全静音（−240 dB）** |

全片现在只有 BGM + 标记位置的音效，没有任何"陪衬音效"。

### 1.2 音色按对标视频实测重做

先从对标视频里量了音效特征（`ffmpeg` 抽 PCM → 分频带 → 找高频瞬态 → 测衰减时间）：

```
频段占比  sub(20-120Hz) 0.322 ｜ low(120-500) 0.215 ｜ mid(500-2.5k) 0.204
          hi(2.5-9k) 0.194 ｜ vhi(9-20k) 0.064
衰减到 10%  0.06 – 0.14 s（极短）
能量中心    47 – 400 Hz
```

**结论：对标片的音效是"短、暗、实"，不是"亮、长、飘"。**

我上一版用的 1320Hz 长衰减钟琴（decay 0.55s）比对标亮一个八度、长三倍，听起来像"游戏音效"而不是"电影音效"。这一版全部重写：

| 音色 | 频段 | 衰减 | 用途 |
|---|---|---|---|
| `hit` | 46–116Hz 基频 + 二次谐波 | 0.085s | 主数字落点、章卡 |
| `ping` | 175–247Hz 基频 + 1.5×/2.02× 泛音 | 0.070s | 中频点、金色出现 |
| `tick` | 294–370Hz | 0.032s | 极短计数点（三连击的第一下） |
| `knock` | 216–264Hz + 2.7× 泛音 | 0.048s | 木质叩击（三连击的第二下） |
| `glass` | 988–1174Hz（衰减压到 0.055s） | 0.055s | 只给"金点变黄"这种需要一点亮度的时刻 |
| `thump` | 58Hz | 0.060s | 给大字垫一层低频触感 |
| `sweep` | 150→880Hz | 0.22s | 短扫频（备用） |
| `suck` | 700→220Hz | 0.16s | 反转吸入（备用） |

### 1.3 多样化怎么做的

**同一个音色在不同位置换基频**，不让观众听出重复：

```
hit   → 104 / 92 / 110 / 98 / 86 / 116 Hz 轮换
ping  → 196 / 220 / 175 / 247 / 208 / 185 Hz 轮换
tick  → 330 / 294 / 370 / 312 / 349 Hz 轮换
knock → 240 / 216 / 264 / 228 Hz 轮换
glass → 1100 / 988 / 1174 Hz 轮换
```

**组合方式也不重复**：
- 单个落点 = `hit`（重）
- 金色时刻 = `hit` + `glass`（重 + 亮）
- 三连击 = `tick` → `knock` → `hit`（"哒-哒-咚"递进）
- 变化时刻 = `glass` + `knock`（亮 + 脆）
- 章卡 = `hit` + `knock`（重 + 实）
- 大字 = `hit` + `thump`（重 + 低频触感）

**声像**：`tick` / `ping` / `glass` 交替轻微左右（±0.20），低频始终居中 —— 避免所有音效挤在正中糊成一团。

## 四·五、音效：叮叮叮 + 不重复（第 8 版）

用户反馈："**音效有点重复**"。

### 问题

第 7 版只用了 5 个 `pro_notify/ding_*` 音色轮换，36 个落点 → 每个音色重复 7 次，
连续听就是"同一个叮叮叮"。

### 解法：音色 × 音高 双维度组合

earshot 的 bank 里只有 5 个 ding，但 `bank.render(..., pitch=Hz)` 能把任意铃音
调到指定音高（实测精确到 0.5Hz）。所以：

**A) 8 个可调音高的铃音** × 多个音高
```
pro_notify/ding_1822 / ding_1930 / ding_2045 / ding_2167 / ding_2296
mallet/glock（钟琴）
```

**B) 6 个固定音高但频谱落在"叮"频段的短脆音**（换音色族，不只是换音高）
```
pro_pop/tink   2646Hz    click/thock    2292Hz
knock/plastic  2898Hz    pro_tap/knock  1831Hz
pop/1          1814Hz    ui_pop/blip    1851Hz
```

**分配规则**：每 4 个落点里 3 个用可调铃音（换音高）、1 个用固定音色（换音色族）。
音高在 1800–2540Hz 之间按 20 档递增，音色按 8 个轮换。

### 结果

| 指标 | 第 7 版 | 第 8 版 | 对标片 |
|---|---|---|---|
| 用到的不同音效 | 5 | **33** | — |
| 不同主频 | 6 | **13–17** | — |
| 音效频谱质心 | 2702 Hz | **2772 Hz** | 2645 Hz |
| 落点突出量 | +12.7 ~ +19.2 dB | **+13.4 ~ +19.4 dB** | — |
| ≥10dB 达标 | 36/36 | **36/36** | — |
| 综合响度 | −17.4 LUFS | **−17.0 LUFS** | — |
| True Peak | −2.1 dBTP | **−2.2 dBTP** | — |

**36 个落点用了 33 种不同音效**（只有 3 处轻微撞车），连续听不会有"同一个音重复"的感觉。
