# 古代七大奇迹 · 1 SURVIVES

50 秒 / 1920×1080 / 30fps。MotionHarness 工程，全部画面代码绘制，无素材贴图。

主题：公元前三世纪流传下来的一份名单，**七座建筑只剩一座还在**。

## 名单与数据

| # | 名称 | 高度/规模 | 结局 |
|---|---|---|---|
| 01 | 空中花园 | 25 米 · 台地总高 | 是否存在仍有争议 |
| 02 | 宙斯神像 | 12.4 米 · 坐像高度 | 毁于大火（公元 5 世纪） |
| 03 | 阿尔忒弥斯神庙 | 127 根 · 石柱总数 | 被纵火焚毁（前 356 年） |
| 04 | 摩索拉斯陵墓 | 45 米 · 建筑高度 | 毁于地震（12 世纪） |
| 05 | 罗德岛巨像 | 33 米 · 铜像高度 | 地震倒塌（前 226 年） |
| 06 | 亚历山大灯塔 | 100 米以上 · 总高 | 毁于地震（1303 年） |
| 07 | 胡夫金字塔 | 146.6 米 · 原高 | **仅存** |

## 结构

```
src/
  scene.js        主入口：镜头调度、文字排版、计数动画
  lib/shapes.js   七座建筑的线框几何 + 数据表（name/years/notes/stat/fate）
  lib/gfx.js      线框绘制、辉光、错开显现
  lib/bg.js       背景网格与粒子
assets/
  music.mp3       BGM
  sfx/            9 个音效（whoosh/impact/glitch/shatter/tick/riser/shimmer/drone/sub）
```

## 音效

全部音效在 `mh.json` 里逐条写在时间轴上，共 90 条 —— 每个切点、每次数字跳动、每座建筑的显现都有自己的声音。

## 运行

```bash
mh open seven-wonders --browser
mh render out.mp4 --json '{"fps":30,"quality":"high"}'
```
